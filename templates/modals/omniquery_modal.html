    🌌 OmniQuery AI-SQL Guide

    OmniQuery does NOT replace the standard "Filters" panel.

    The standard Filters panel is incredibly powerful and easy to use as a form. However, if you have highly specific needs, are a power user, or want to save unique search criteria, OmniQuery is the brilliant, original solution.

    🗣️ Natural Language Search

    OmniQuery exposes all database tables so you can cross-reference your data using natural language. It acts as an expert Prompt Engineer, preparing a tailored prompt that you can submit to your favorite LLM. The LLM will return the "magic" SQL query to run here.

    🛡️ Bulletproof Security

    Your data is completely safe. The SmartGallery DAM backend strictly allows only SELECT (read-only) queries. Updates or destructive commands are physically blocked.

    💻 For SQL Veterans

    If you know SQL, you can compose the query yourself! In the first part of the prompt panel, you will find the full database structure and rules to cross-reference data.
